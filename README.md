# 学习目标管理台

一个帮你**把目标拆成每天可打卡的小步**的单文件 Web 应用。零依赖、纯前端、数据存在本地浏览器，离线也能用，还能像 App 一样装到手机主屏幕。

## ✨ 功能特性

- **今日打卡**：为每个目标预填「今日建议量」，一键记录完成量与投入分钟，实时查看剩余进度与截止日。
- **目标看板**：新建 / 编辑 / 删除目标，支持名称、单位、总量、截止日、**配色**、**障碍预判**与**应对对策**（提前想好「它会怎么拦住我、我该怎么破」）。
- **周报复盘**：自动统计每周投入量、打卡天数、投入分钟，并与上周环比；内置「保持 / 问题 / 尝试 / 下周预案」四栏复盘，一键生成可复制的周报文本（方便贴到微信 / 备忘录）。
- **数据备份**：一键导出全部目标与打卡记录为 JSON；支持导入覆盖恢复，导入前二次确认，避免误删。
- **旧版迁移**：检测旧格式数据并补全字段，升级不丢数据。
- **离线可用 + 主屏图标**：可添加到手机主屏幕，像原生 App 一样随时打开。

## 🛠 技术栈

- 纯 `HTML + CSS + 原生 JavaScript`，**零第三方依赖、零构建步骤**。
- 数据使用浏览器 `localStorage` 持久化，不上传任何服务器。
- 图标 `favicon.svg`（紫色目标靶心，呼应「对准目标」）。

## 📁 目录结构

```
learning-goals/
```

## 🚀 使用方式

### 本地打开
直接双击 `index.html` 用浏览器打开即可使用（推荐 Chrome / Edge / Safari）。

> 说明：部分浏览器在 `file://` 协议下会限制导出下载等能力。若导出 / 导入异常，建议用本地静态服务器打开：
> ```bash
> cd learning-goals
> python -m http.server 8080
> # 然后访问 http://localhost:8080/
> ```

### 部署到 Gitee Pages
1. 将本仓库推送到 Gitee。
2. 进入仓库「服务 → Gitee Pages」，选择分支（默认 `master`），部署目录为根目录，建议开启强制 HTTPS。
3. 部署完成后即可通过页面地址在线访问。

### 添加到手机主屏幕
- **iPhone（Safari）**：点底部「分享」图标 → 选「添加到主屏幕」。
- **安卓（Chrome）**：点右上「⋯」菜单 → 选「安装应用 / 添加到主屏幕」。

## 💾 数据说明

- 所有数据仅保存在**当前浏览器**的 `localStorage` 中，清除浏览器数据或换设备会丢失。
- 换设备或清理浏览器前，请务必在「我的 → 数据备份」中导出 JSON 备份。
- 导入会**覆盖**当前全部数据，请先确认已备份。
